# ⛏ Voxelcraft · 网页版 3D 我的世界

基于 **Three.js** 的纯前端体素沙盒小游戏（H5，无构建工具、无后端、离线可玩）。
机制数据对齐原版 Minecraft（来源：minecraft.wiki，2026-09-22 抓取）。

## 运行

ES Module 需要 HTTP 环境，任选其一（**注意：8000 端口已被本机其他程序占用，请勿使用；默认用 8471**）：

```bash
# 方式 1：Python
python -m http.server 8471 -d voxelcraft

# 方式 2：VS Code Live Server 插件（可自定义端口），右键 index.html → Open with Live Server
```

然后浏览器打开 `http://localhost:8471`，点击画面任意处开始。
若 8471 也被占用，换任意空闲端口即可（如 8500）。

## 操作

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动 |
| 空格 | 跳跃（水中为游泳） |
| Ctrl / X | 疾跑 |
| 鼠标 | 视角（Pointer Lock） |
| 按住左键 | 挖掘方块（按原版硬度计时：泥土 0.75s、石头 2.25s、圆石 3.0s） |

| 1-9 / 滚轮 | 切换热键栏 9 格 |
| Esc | 释放鼠标 |

## 对齐原版的机制（minecraft.wiki 数据）

- 步行速度 **4.317** 格/秒，疾跑 **5.612** 格/秒
- 跳跃高度 **1.25** 格（v₀ = √(2·g·h)，g = 0.08×20² = 32 格/秒²）
- 重力 **0.08 格/tick²**，终端速度 ×0.98（20 ticks/s，固定物理子步）
- 玩家身高 1.8 格、眼高 1.62 格、半宽 0.3 格
- 昼夜循环 **20 分钟** = 24000 ticks（天空/雾/光照按关键帧渐变，太阳月亮绕天球）
- 方块硬度：草 0.6 / 泥土 0.5 / 石头 1.5 / 圆石 2.0 / 木板·原木 2.0 / 树叶 0.2 / 玻璃 0.3 / 雪 0.1；**基岩 hardness = -1 不可破坏**
- 地形分层：基岩（1~3 层）→ 石头 → 泥土 → 草方块；海平面 y=28，水下沙质海床，高地雪顶，随机橡树

## 技术实现

```
voxelcraft/
├── index.html          页面 + UI（热键栏/准星/HUD/开始遮罩）
├── css/style.css
├── lib/three.module.min.js   three.js 0.170（本地化，离线可玩）
└── js/
    ├── constants.js    原版机制数据与方块定义
    ├── noise.js        带种子 Perlin 噪声 + fBm
    ├── textures.js     程序化 16×16 像素纹理图集（17 图块，无外部图片）
    ├── world.js        体素存储 + 地形生成 + 树木 + 出生点
    ├── mesher.js       区块网格化：面剔除 + 顶点色 AO + 水面单独几何
    ├── player.js       AABB 碰撞、逐轴分离、原版重力/跳跃
    ├── raycast.js      体素 DDA 射线（Amanatides & Woo）
    ├── daycycle.js     20 分钟昼夜循环（天空/雾/太阳/月亮关键帧）
    ├── input.js        Pointer Lock / 键盘 / 鼠标 / 热键栏
    └── main.js         场景、区块管理、破坏放置、游戏主循环
```

- 世界 96×64×96，16×16 区块；编辑方块时只重建受影响的 1~9 个区块
- 不透明面剔除 + 透明方块（水/玻璃/树叶）特殊处理；水为半透明材质、顶面降低 0.12
- 纹理图集 272×16，NearestFilter 像素风；AO 四角烘焙进顶点色
