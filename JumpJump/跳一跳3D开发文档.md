# 跳一跳3D游戏开发文档

## 项目概述

基于 Three.js 开发的 3D 版跳一跳 H5 游戏，完全模仿微信小程序跳一跳的玩法和机制，并添加了真实的物理引擎系统。

**开发时间**：2026年9月21日  
**技术栈**：Three.js (r128), 原生 JavaScript, HTML5, CSS3  
**文件大小**：约 30KB（单文件）

---

## 核心功能

### 1. 基础玩法

- **长按蓄力跳跃**：按住屏幕/鼠标蓄力（最多2秒），松手后棋子跳跃
- **蓄力进度条**：实时显示当前蓄力百分比（渐变色：绿→黄→红）
- **虚拟抛物线**：蓄力时显示白色半透明虚线，实时预览跳跃轨迹
- **3D渲染**：完整的 3D 场景，带阴影、光照和雾化效果
- **平滑相机**：摄像机平滑跟随棋子，视角自然流畅

### 2. 计分系统

#### 基础得分
- 普通落地：+1分
- 跳到平台中心（20%范围内）：连击加分
  - 连击1次：+2分
  - 连击2次：+4分
  - 连击3次：+6分
  - ...最高连击16次：+32分

#### 大跳加分
- 跳过1个平台：额外+2分
- 跳过2个平台：额外+4分
- 跳过N个平台：额外+2N分

#### 特殊平台加分
- 🎵 音乐盒（黄色）：+30分
- 🏪 便利店（绿色）：+15分
- 🎲 魔方（紫色）：+10分
- 🚰 井盖（深紫色）：+5分

### 3. 真实物理引擎

#### 重力系统
- 重力加速度：-20 m/s²
- 初始上升速度：5 m/s
- 水平速度：根据蓄力时间计算（0-8 m/s）

#### 重心判定系统
- **安全区域**：距离平台边缘 ≥ 0.25 单位
- **不稳定区域**：距离平台边缘 < 0.25 单位
- **自动判定**：每次落地自动计算重心位置

#### 阻尼振荡系统
- **稳定时间**：1.2秒
- **衰减系数**：e^(-2.5t)（指数衰减）
- **振荡频率**：6 Hz
- **摇晃方向**：
  - X轴旋转：前后摇晃
  - Z轴旋转：左右摇晃
- **失衡临界点**：总倾斜角度 > 23度（0.4弧度）

#### 碰撞物理系统
- **顶部落地**：正常站立，进入稳定判定
- **侧面碰撞**：反弹并旋转
  - 恢复系数：0.3（反弹30%动能）
  - 摩擦系数：0.7（保留70%切向速度）
  - 碰撞类型：左右侧面、前后侧面、边角碰撞
- **碰撞体**：
  - 棋子：圆柱体（半径0.35，高度1）
  - 平台：立方体（尺寸0.9-1.5可变）

## 游戏参数

### 平台生成
- **距离范围**：2.0 - 5.5 单位
- **尺寸范围**：0.9 - 1.5 单位
- **方向**：随机（向前或向右）
- **特殊平台概率**：10%
- **最大可见平台数**：8个

### 跳跃参数
- **最大蓄力时间**：2秒
- **蓄力系数**：× 4
- **理论最大距离**：8单位
- **实际最大距离**：6单位（平台最远5.5 + 余量0.5）
- **跳跃动画**：轻微前倾17度（0.3弧度）

### 物理参数
- **边缘安全距离**：0.25 单位
- **不稳定摇晃强度**：0.225-0.45 弧度（13-26度）
- **稳定摇晃强度**：0.12 弧度（7度）
- **失衡角度**：0.4 弧度（23度）
- **稳定时间**：1.2 秒

## 技术实现

### Three.js 场景配置

```javascript
// 场景
scene.background = 0x87CEEB (天空蓝)
scene.fog = Fog(0x87CEEB, 10, 50)

// 相机
camera = PerspectiveCamera(45度, aspect, 0.1, 100)
camera.position = (5, 8, 12)

// 光照
ambientLight: 0.6 强度
directionalLight: 0.8 强度, 位置(5, 10, 5)
阴影: PCFSoftShadowMap, 2048×2048
```

### 棋子模型

```javascript
// 几何体：圆锥台
CylinderGeometry(
  topRadius: 0.3,
  bottomRadius: 0.4,
  height: 1,
  segments: 8
)

// 材质
MeshStandardMaterial(
  color: 0x2C3E50 (深蓝灰),
  metalness: 0.3,
  roughness: 0.7
)
```

### 抛物线渲染

```javascript
// 材质：虚线
LineDashedMaterial(
  color: 0xFFFFFF (白色),
  dashSize: 0.2,
  gapSize: 0.1,
  opacity: 0.6
)

// 采样：30个点，步长0.05秒
// 物理模拟：重力-20，初速度根据蓄力计算
```

### 碰撞检测算法

```javascript
// 1. 遍历所有平台
for (platform in platforms) {
  // 2. 检测XYZ三轴重叠
  inXRange = |dx| <= halfWidth + playerRadius
  inZRange = |dz| <= halfDepth + playerRadius
  inYRange = playerBottom <= platformTop && playerTop >= platformBottom
  
  // 3. 判断碰撞类型
  if (在平台顶部范围内) {
    // 顶部落地
    calculateStability()
    startStabilizing()
  } else if (侧面碰撞) {
    // 计算法向量
    normal = calculateCollisionNormal()
    // 应用反弹
    applyReflection(normal, restitution=0.3, friction=0.7)
  }
}
```

## 总结

这是一个高度还原微信跳一跳的3D游戏，具有以下特点：

✅ **真实物理**：重力、重心、阻尼、碰撞全模拟  
✅ **流畅体验**：平滑动画、相机跟随、视觉反馈  
✅ **丰富玩法**：连击、大跳、特殊平台多种得分方式  
✅ **休闲友好**：难度适中，容错率高，适合放松游玩  
✅ **单文件实现**：无需构建工具，直接打开即可游玩  

**开发重点**：
- 物理引擎的真实感（90%的开发时间）
- 游戏性与挑战性的平衡
- 视觉流畅度和反馈

**下一步目标**：
- 添加动态能量加成系统
- 优化跳跃体验，确保所有平台都能轻松跳到
